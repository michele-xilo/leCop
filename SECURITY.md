# Security policy

## Supported versions

Only the latest release of leCop receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
[Report a vulnerability](https://github.com/michele-xilo/leCop/security/advisories/new).

Include the leCop version, how you installed it, and the smallest input that shows the problem. A crafted dataset that
makes leCop crash, hang or read files outside the dataset directory is in scope. A dataset leCop rejects or reports
wrongly is a normal bug: open an issue.

You can expect an acknowledgement within a few days. We will agree on a disclosure date with you and credit you in the
release notes unless you prefer not to be named.
